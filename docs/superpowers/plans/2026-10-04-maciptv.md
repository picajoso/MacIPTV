# MacIPTV Implementation Plan

**Goal:** Deliver a native macOS viewer with a familiar IPTV channel/guide/player workflow.
**Architecture:** Swift package with MacIPTVCore library and MacIPTV executable. Pure parsers and endpoint builders support the SwiftUI state store and AVKit player.
**Tech Stack:** Swift 6 tools, Swift 5 language mode if useful, SwiftUI, AppKit, AVKit, Foundation XMLParser, Security Keychain; macOS 14 minimum.
**Spec:** docs/superpowers/specs/2026-10-04-maciptv-design.md

## Review focus
Credential-bearing URLs cannot enter logs/UserDefaults. Failed imports retain active source. Late refreshes cannot replace a newer source. Empty lists are errors. XMLTV uses channel IDs/timezones and remains responsive for large guides. Demo is labeled and never silently overwrites provider configuration.
